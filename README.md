# SUN GLASS

周囲の光をARKitで推定し、夏のステンドグラスへ少しずつ焼き付けるiPhoneアプリです。

## 実装済み

- 4ステップの新規作品作成（テーマ、期間、基調色、共同制作設定）
- 7テーマ対応の決定論的なプロシージャル・ステンドグラス
- ARKit `ARLightEstimate` による光強度・色温度の計測
- 外れ値除外、3秒移動平均、5段階の光レベル
- 1回30秒の自動終了、1日90秒の反映上限、端末温度による安全停止
- 光ポイント、時間帯、色温度、光レベル、継続日数からの作品進行とガラス片生成
- 保存済みガラス片・写真色をホーム、鑑賞、AR配色、書き出しへ一貫して反映
- Application Supportへのatomic JSON保存、直前世代バックアップ、破損時復旧、schema migration
- 計測中の0.5秒ドラフトと強制終了後の復元、保存失敗時のロールバック
- コンテナ移動に耐える相対写真パス、写真差し替え・作品削除時のファイル整理
- 日別カレンダー、一言、1日1枚の写真、最大5色・明るさ・輪郭密度の端末内解析
- ドラッグ・ピンチ・長押し・端末傾きに対応した鑑賞モード
- 実際のガラス片の形・位置・色を使うRealityKit AR配置、拡縮、回転、色付き投影
- AR写真共有、ReplayKit動画撮影、権限拒否・非対応・平面未検出の案内
- 正方形、9:16、16:9、A4の画像出力
- AVAssetWriterによる10秒の制作タイムラプス・光透過動画・写真背景付き日別記録動画
- ロック画面、ホーム画面、背景／透明前景に分けた奥行き壁紙
- 招待コード、QRコード、`sunglass://` 招待リンク、最大10人の共同制作データモデル
- 初回案内と設定から、室内・窓辺を各10秒実測する端末別キャリブレーション
- 作品ごとに任意の位置記録（1回取得、約100mへ丸めて端末保存、座標だけ削除可能）
- VoiceOver、色以外の状態表示、視差・発光軽減
- カメラ映像を保存・送信しないプライバシー設計

## 実行

Xcode 26以上で `SunGlass.xcodeproj` を開き、iOS 26以上のiPhoneを選択して実行します。シミュレータでは、実カメラの代わりに変化するデモ光が入力されます。

```sh
xcodebuild \
  -project SunGlass.xcodeproj \
  -scheme SunGlass \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  CODE_SIGNING_ALLOWED=NO \
  build
```

## データとバックエンド

現時点のアプリはローカルファーストです。作品・光セッション・写真パス・写真解析値・一言・参加者はすべて端末内へ即時保存され、ネットワークがなくても制作と鑑賞を続けられます。

仕様書にあるSupabase Authentication、PostgreSQL、Storage、Realtimeを実際の複数端末間で動かすには、SupabaseプロジェクトURL、公開キー、データベース、Storage bucket、RLS policyが必要です。このリポジトリには認証情報とサーバースキーマが提供されていないため、ネットワーク同期、他端末からの招待参加、展示用大型画面のRealtime配信は接続していません。共同制作のローカルモデル、招待コード、QR/URL導線、担当領域、参加上限と画面は実装済みです。

## 安全上の前提

SUN GLASSが扱う値は、カメラから推定した作品生成用の相対的な環境光です。紫外線量、実際の日焼け量、健康への影響は測定しません。太陽へ直接カメラを向けたり、端末を直射日光下へ放置したりしないでください。
